# Скачивание папки с Яндекс.Диска по одному файлу

```bash
pip install requests
python yadisk_download.py "https://disk.yandex.ru/d/ВАША_ССЫЛКА" -o ./mebel_2024
```

- Ссылка должна быть публичной («Поделиться» → «Включить доступ по ссылке»).
- Если ссылка ведёт на корень, а нужна подпапка: `--path "/Мебель 2024"`.
- `--list` — только показать файлы и общий размер.
- Скрипт можно прерывать и запускать снова: готовые файлы пропускаются, недокачанные докачиваются.
- Неудавшиеся файлы пишутся в `_failed.txt`.
