# Правила для скриптов в этом репозитории

- Общение и все сообщения скриптов — на русском.
- Любой скрипт автоматизации обязательно сохраняет историю работы:
  - журнал (`log.txt`): каждый запуск с датой и временем, каждый шаг, каждая ошибка с текстом;
  - состояние (`state.json` или аналог): что уже сделано, чтобы не повторять работу после перезапуска;
  - при ошибке в браузерной автоматизации — скриншот (`debug_*.png`).
- Журналы и состояние не коммитятся (добавлять в `.gitignore`).
